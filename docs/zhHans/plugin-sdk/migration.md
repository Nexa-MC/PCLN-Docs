# 从旧 SDK 迁移

旧仓库已更名为 NexaCL-Plugin-SDK，Git 历史保留。当前分支替换旧 PCL.N.Plugin.* 项目、注入接口、UI 适配器和分析器；这不是旧二进制的兼容包装层。

| 原方式 | 新方式 |
| --- | --- |
| CLR 注入及宿主对象 | 隔离的无导入 Wasm 与明确能力调用 |
| 进程内 UI 访问 | 验证过的 NXML 资源和宿主渲染 |
| 任意文件路径 | 显式文件授权与业务计划 |
| 隐式服务访问 | 必需／可选契约协商和权限检查 |

先列出插件实际使用的宿主功能，再逐项寻找已接入的公开能力。将页面移入包资源，把直接调用改为类型化操作，补上取消、释放和失败处理。不能只改命名空间或把旧编号解释成 ABI 100 编号。

现有 Nexa ABI 100 从 alpha.9 到独立 SDK alpha.10 保留 Bootstrap 签名、346 个操作、模型字段和指纹，主要变化是源码归属和分发方式。22 个保留的 Nexa 预览槽位属于另一份兼容目录，与旧 PCL 注入接口无关。

从模板重新构建后，验证实际需要的能力、拒绝路径和停止重载；未接入能力需要保持不可用，不能因为 SDK 有包装器就承诺功能完成。
