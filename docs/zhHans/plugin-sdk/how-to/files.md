# 访问包内资源与用户文件

包内资源依靠清单摘要绑定；用户文件需要宿主授权。路径字符串、界面显示的路径或其他插件持有的 FileRef 都不能代替授权。

## 打开包内资源

把资源加入 payload 清单，编辑后重新构建摘要。以准确的相对路径调用 Files.OpenPackageFile，例如 `page.nxml`，再把返回的 FileRef 传给页面注册等接口。

ZIP 中多包一层目录会改变路径。不要加入符号链接或越界路径，也不能从包内文件授权推导安装目录的读取权限。

## 请求用户文件

使用规定的选择器或授权接口，并尊重取消。只访问授权范围，不把选中文件扩展为父目录、相邻文件或范围外的符号链接目标。

按范围读取，区分短读、文件结束和失败。替换写入使用原子写及其版本要求；监听发生缺口后重新读取实际状态。

## 管理数据寿命

BlobRef 是宿主保存字节的不透明句柄，不是内容本身，也不能跨重启当作持久引用。只使用该资源类型明确规定的释放方式，不要假定有通用释放接口。

测试取消选择、摘要不匹配、授权撤销以及读写之间文件被修改。日志中避免记录文件内容和私人路径。详细字段见 [Files](../api/files.md) 与 [Platform](../api/platform.md)。
