# 预览并执行修改

实例创建、内容变更和主题应用等操作提供准备或计划步骤。具体计划类型可能不同，应以该领域的操作参考为准。

## 固定用户确认的内容

读取目标状态，用准确的输入生成计划，保存计划身份和版本，通过宿主展示其真实摘要。准备计划不等于执行副作用。

批准后提交同一个计划。宿主重新检查权限、归属和目标版本；如果等待期间目标变化，应重新准备，必要时再次确认。不要把新的目标或参数塞进已经批准的计划。

## 等待真实结果

返回 OperationRef 时继续观察终态；直接返回结果时先检查 Success。取消不等于回滚。计划可能只能使用一次，也可能绑定当前加载；失效、已消费或外来计划应重新准备。

幂等键标识预期副作用，不是修复无效计划的通行证。结果不确定时保留原键与输入，再查询任务记录。

## 验证冲突

先准备计划，再通过另一条合法操作改变目标，最后提交旧计划。预期应是冲突而非执行未经复核的修改。再测试拒绝、重复提交、停止插件和权限缺失。
