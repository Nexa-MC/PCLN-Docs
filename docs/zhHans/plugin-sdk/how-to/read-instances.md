# 读取实例列表

使用 Minecraft.Instances 读取宿主管理的实例，而不是扫描任意目录来猜测实例身份。请求准确的读取权限并协商能力后，再调用 List。

## 分页读取

第一次请求不携带游标，并设置合理的数量上限。读取 Items 后，在相同查询中传回 NextCursor，直到游标缺失。游标无效是失败，不是列表结束；需要时从头重新读取。

游标可能绑定查询、提供方、作用域和加载实例，不能解码、递增或交给其他插件。实例 ID 同样不能从名称或路径构造。

## 保持选择与读取独立

列出实例不会替用户选中它，也不会授权启动。后续操作使用返回的身份；只有用户确实请求选择或启动时才调用对应操作。

订阅发生缺口时重新读取完整快照，并按身份恢复界面选择。原实例消失时明确显示其不可用，不能为修改操作自动换成另一个实例。

验证空列表、多页、分页中删除实例和权限拒绝。读取失败必须与“没有实例”区分。详细字段见 [Instances 参考](../api/minecraft-instances.md)。
