# NTP/1 theme authoring

This guide targets **NexaCL Firefly Alpha 12**. NTP/1 themes are appearance packages, separate from legacy PCL N plugins and executable Sidecars.

Themes supply styles, finite animation, admitted resources and options rendered by the host. They cannot replace NXML pages, create business commands, execute scripts or read arbitrary external files.

## Learning path

1. [Your first theme](quick-start): a working directory, example and reproducible package.
2. [Manifest and controls](manifest-and-options): value types, switches, sliders and live application.
3. [Styles and resources](styles-and-resources): NSS/1, light/dark adaptation and resource grants.
4. [Testing and publishing](testing-and-publishing): limits, recovery and the distribution checklist.

NTP/1, NSS/1, styleApi and the launcher product version are separate identities. User reduced motion, safe mode and recovery policies take precedence. Missing required capabilities reject activation; optional capabilities need declared fallbacks.
